## 🏁 Getting Started

### Prerequisites

| Tool | Version |
|:---|:---|
| Node.js | 18+ |
| npm / yarn | Latest |

### Setup

```bash
git clone https://github.com/krishkantrai27/portfolio.git
cd portfolio
npm install
npm run dev
```

Open `http://localhost:5173` (or the port shown in terminal) to view it locally.

### Build for production

```bash
npm run build
```
