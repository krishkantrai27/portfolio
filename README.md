## 🚀 Overview

Personal software engineering portfolio presenting key projects, technical skill stack, and interactive AI assistant built with Astro, Preact, Tailwind CSS, and Netlify Functions.

### 🌟 Featured Projects

1. **StackForge**: Zero-dependency vector database in Java 17+ featuring HNSW, KD-Tree, and Brute-Force search algorithms, integrated with local Ollama RAG pipelines and real-time 2D PCA vector projections.
2. **ProbeLink**: ISP Network Infrastructure Planning & Site Survey platform for MDUs and campuses with interactive floor plan canvases, RF heatmaps, and automated iText PDF report generation.
3. **FarmXchange**: Transparent agricultural supply chain marketplace connecting farmers directly with buyers featuring role-based verification, wallet transactions, and order tracking.
4. **Blog Application**: Modern full-stack blogging platform with Spring Boot backend, JWT authentication, rich media post management, and interactive author analytics.

### 🤖 AI Assistant Integration

Features a embedded Preact AI Chat Assistant widget powered by Netlify Functions (`/netlify/functions/chat.mjs`) and portfolio knowledge context (`/netlify/lib/knowledge.mjs`), delivering intelligent responses about projects, technical skills, and experience.

## 🏁 Getting Started

### Local Setup

```bash
# Clone the repository
git clone https://github.com/krishkantrai27/portfolio.git
cd portfolio

# Install dependencies
npm install

# Start local dev server
npm run dev
```

### Build for Production

```bash
npm run build
```
